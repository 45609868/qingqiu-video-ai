# 剧本改写指南

> **风格二选一**：drama.style 仅 `anime`（国漫古风玄幻）或 `real`（古装真人）。其他风格已废弃。

## 工作流程

1. 调用 `read_episode_script` 读取原文
2. 按总编策略 + 风格基准改写
3. 按原文时间顺序自然叙事
4. 直接输出改写结果（不调 `save_script`）

---

## 风格核心差异

### anime — 国漫古风玄幻

题材母题（任意组合）：
- 修仙飞升 / 宗门争斗 / 秘境夺宝
- 妖怪图鉴 / 妖族复仇 / 人妖之恋
- 废柴逆袭 / 血脉觉醒 / 装逼打脸
- 山海经异兽 / 神话再演绎 / 西游衍生
- 古风权谋 / 江湖恩怨 / 押镖冒险

视觉与节奏特征：
- 节奏：60-90 秒 / 集，开场 3 秒必有冲突或悬念
- 场景：7-10 个 / 集，平均 100-150 字
- 对话比：70-80%
- 视觉：依赖特效（仙剑 / 法阵 / 妖气）撑场面
- 台词：短、狠、可表演，单句 ≤ 20 字

### real — 古装真人

题材母题（任意组合）：
- 宫斗权谋 / 后宫争宠
- 江湖恩怨 / 镖局风云 / 武林争霸
- 战神回归 / 将军复仇 / 边关战事
- 民间奇案 / 侠义探案
- 神怪志异 / 鬼狐仙妖

视觉与节奏特征：
- 节奏：90-120 秒 / 集，开场 5 秒必有冲突
- 场景：6-9 个 / 集，平均 150-200 字
- 对话比：60-70%
- 视觉：依赖演员微表情 / 真实环境
- 台词：更贴近口语，肢体语言更重

---

## 通用爆款指标（必须严格遵守）

### 1. 句长控制
- 平均句长：10-14 字符
- 短句（< 10 字符）：30-40%
- 中句（10-20 字符）：50-60%
- 长句（≥ 20 字符）：< 10%
- 长句必须拆为 2-3 个短句

### 2. 对话比
- 目标：70-80% 对话 / 旁白
- 每 1000 字：15-25 条对话
- 平均对话：20-40 字符
- **必须**把叙述改成对话

❌ 原：她很生气，觉得他太过分了。
✅ 改："你太过分了！"她冷冷道。

### 3. 视觉标记密度（每 100 字）
- 表情（冷笑、嗤笑、狞笑）：1.5 个
- 眼神（眼神一冷、瞳孔一缩）：1.0 个
- 动作（挑眉、握拳、转身）：1.0 个
- 气场（霸气、凌厉、冷气逼人）：0.5 个
- 合计：≥ 4 个 / 100 字

### 4. 网文感关键词（每 100 字 1.5-2.5 个）
- 情绪：冷笑 / 嗤笑 / 冷哼 / 冷声
- 态度：不屑 / 轻蔑 / 讥讽 / 嘲讽
- 气场：霸气 / 强势 / 凌厉 / 凛然
- 反转：没想到 / 竟然 / 居然 / 突然
- 打脸：当场打脸 / 脸色一变 / 啪啪打脸

### 5. 节奏感
- 每 2-3 个镜头必有信息 / 情绪变化
- 冲突密度 ≥ 0.03（冲突次数 / 总字数）
- 禁止连续 3 句以上平稳对话

## 短剧节奏模板

### anime — 60-90 秒 / 集

```
S01（前 3 秒）：强钩子，抛出核心冲突
S02-S03：建立人物 + 第一个信息
S04（小高潮）：情绪爆发 / 信息揭晓
S05（转折）：意外事件 / 身份反转
S06-S07：收尾 + 留悬念（下一集）
```

### real — 90-120 秒 / 集

```
S01（前 5 秒）：强钩子，抛出核心冲突
S02-S04：建立人物关系 + 第一个冲突
S05-S06：升级矛盾 / 信息揭晓
S07-S08：高潮对决 / 情绪爆发
S09：留悬念（下一集）
```

## 台词硬规则

- 每句台词 ≤ 20 字（硬性，超出必须拆）
- 口语化：演员能直接念的台词
- 禁止第三人称心理描写
- 强制转为可表演的台词 + 动作描述

❌ 错：XXX 想到，这家伙一定有秘密。
✅ 对："说！你背后到底是谁？"（冷声质问）

---

## 冲突触发规则

- 每 3 句台词内必须触发一次小冲突
- 小冲突类型：质问 / 威胁 / 嘲讽 / 揭穿 / 拒绝 / 哭诉 / 崩溃
- 情绪变化：冷笑→震怒 / 惊讶→恐惧 / 沉默→爆发
- 禁止连续 3 句以上平稳对话

---

## 风格适配 prompt 注入

**anime 风格必备：**
- 在场景描述中加视觉特效（仙剑 / 法阵 / 灵气）
- 在情绪爆发点用玄幻术语（"杀意凛然"、"剑意纵横"）
- 在服装描述中加古风元素（道袍 / 襦裙 / 铠甲）

**real 风格必备：**
- 在场景描述中加真实道具（八仙桌 / 雕花窗 / 青石板）
- 在情绪爆发点用写实动作（攥紧拳头 / 摔茶盏 / 抽剑）
- 在服装描述中加真实材质（丝绸 / 棉麻 / 锦缎）

## 格式化剧本模板

```
# 第X集《标题》

## S01 | 内景/外景 · 地点 | 时间段
戏剧功能：钩子
动作：{可拍到的动作+表情+道具}
对白：
  角色A：{情绪+动作}台词
  角色B：{情绪+动作}台词
旁白：{≤20字信息压缩}
转场：cut

## S02 | ...
```

每场必须包含：
- 场景头
- 戏剧功能
- 动作
- 对白
- 旁白（必要时）
- 转场

## 自检清单

- [ ] 是否按原文时间顺序自然叙事
- [ ] 每场是否有明确戏剧功能
- [ ] 是否保留主角行动动机
- [ ] 是否没有剧透后续未出现剧情
- [ ] 是否像可拍剧本，不像小说复述
- [ ] 每句台词 ≤ 20 字
- [ ] 是否每 3 句触发小冲突
- [ ] 开场前 3 秒（anime）/ 5 秒（real）是否有强钩子
- [ ] 视觉风格词库是否正确注入（anime 用三渲二/港漫勾线，real 用写实质感）
- [ ] 是否对应 drama.style（anime/real）

## 禁止

- 禁止输出剧情梗概
- 禁止输出分析说明
- 禁止大段心理描写
- 禁止把小说原文整段复制成旁白
- 禁止凭空制造强悬念
- 禁止使用霸总 / 甜宠 / 悬疑 / 现代都市 等已废弃风格术语
