# 剧本改写指南

## 核心原则

1. **小说 vs 剧本**：小说用叙述讲故事，剧本用动作+对话讲故事
2. **视觉化转换**：将抽象的心理描写转为可见的表情/动作/台词
3. **对话驱动**：用对白推动情节，减少旁白
4. **场景拆分**：长段落拆为多个短场景，每场控制在 30-60 秒
5. **不写镜头语言**：不涉及景别、角度、运镜，这些属于分镜步骤

## 小说→剧本转换规则

### 规则1：旁白/内心独白 → 视觉动作 或 画外音

**小说写法**：
> 左登峰在心里将孙爱国和胡茜骂了个狗血喷头，早知道是今天这种局面，当初就该放把火。

**剧本转换**：
```
旁白：左登峰回到文化所，越想越气，孙爱国和胡茜这对狗男女...
或
左登峰回到文化所，在屋里来回踱步，表情阴沉，攥紧拳头。（心里暗骂）
```

### 规则2：叙述性场景 → 角色动作+台词

**小说写法**：
> 左登峰疑惑的凑近门缝，发现文化所的西厢还有灯光，那里是副所长胡茜的办公室。

**剧本转换**：
```
左登峰悄悄走到门口，侧耳倾听。
门缝透出灯光，里面传来女人声音："饶了我吧，我真的不行了。"
```

### 规则3：复杂动作拆解

**小说写法**：
> 左登峰二话不说就踹开房门冲了进去，房间里的办公桌前趴着一个光屁股女人，女人的后面站着一个男人，裤子也褪到了脚脖子。

**剧本转换**：
```
左登峰一脚踹开房门，冲入。
（办公室场景）
女人趴在办公桌上，男人站在后面。
左登峰愣住。
```

### 规则4：心理描写 → 表情/动作暗示

**小说写法**：
> 突如其来的变故令左登峰陷入了短暂的茫然，目瞪口呆的站在原地。

**剧本转换**：
```
左登峰：（愣住，嘴唇微张）
片刻后，才勉强后退一步。
```

### 规则5：场景转换标记

每换一个新场景，用场景头标记：
```
## S01 | 内景 · 文化所 · 夜晚

## S02 | 内景 · 文化所西厢 · 夜晚
```

## 格式化剧本格式

### 标准格式

```markdown
## S01 | 内景 · 咖啡厅 | 黄昏

黄昏的光线透过落地窗洒进咖啡厅，吧台上咖啡杯热气升腾。

小明独自坐在角落卡座，低头看手机，神情有些焦虑。

门铃响起，小红推门而入。她看到小明，微笑着走过去。

小红：（微笑）等很久了吗？
小明：（抬头）还好，刚到。
```

### 格式规则

- `## S编号 | 内景/外景 · 地点 | 时间段` — 场景头（必填）
- 动作描写用自然段叙述 — **不包含任何镜头语言**
- `角色名：（状态/表情）台词内容` — 对白格式（禁止省略角色名）
- 旁白用 `旁白：` 前缀

### 场景头时间要求

时间段要具体：
- ✅ 深夜 / 黄昏 / 清晨 / 正午 / 傍晚 / 深夜子时
- ❌ 白天 / 晚上（太笼统）

## 改写质量检查清单

每个场景保存前自检：
- [ ] 每段叙述都有对应的角色动作或对话
- [ ] 旁白/内心独白已转为可见内容
- [ ] 对话有明确的说话角色
- [ ] 场景头格式正确（内/外景 + 地点 + 具体时间）
- [ ] 每场戏不超过 60 秒阅读量

## 改写步骤

1. 调用 `read_episode_script` 读取原始内容
2. 分析内容结构（对话、叙述、心理描写的比例）
3. 识别主要场景和场景转换点
4. 将叙述性段落转为角色动作+对白
5. 调用 `rewrite_to_screenplay` 执行改写
6. 检查改写结果，确认符合格式化剧本格式
7. 调用 `save_script` 保存最终结果

## 注意事项

- 心理描写可转化为角色表情/动作或画外音
- 长段叙述拆分为多个短场景
- 确保每个场景有明确的情绪转折点
- 保持角色语言风格一致性
- 场景编号连续递增（S01, S02, S03...）
- 时间段要具体（黄昏、深夜、清晨），不要笼统写"白天"
- **民国/古代题材注意服装、道具、场景物品的时代感**

## 时代感描述要求

民国/古代题材额外检查：
- 服装词汇（长袍、马褂、旗袍、学生装、官服等）
- 场景物品（煤油灯、红木家具、土墙、瓦片、牌匾等）
- 社会称谓（少爷、老爷、夫人、官人、丫鬟等）
- 货币单位（大洋、铜板、法币等）

示例 - 民国风格场景描写：
```
## S03 | 内景 · 左登峰宿舍 · 夜晚

煤油灯摇曳，屋内陈设简陋：一张木床，一张书桌，墙上挂着县文化所的牌子。
桌上放着几枚铜板和一块大洋。
```
