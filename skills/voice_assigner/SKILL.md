# 音色分配指南

## 风格硬约束

音色选择必须与项目风格匹配：

- **anime**（国漫古风玄幻）：倾向配音演员 / 二次元少年音 / 古风 CV
- **real**（古装真人）：倾向沉稳自然 / 影视同期声质感

**禁止** 给 anime 角色配现代都市口音；**禁止** 给 real 角色配二次元"嗲音"。

---

## 分配原则（4 维匹配）

1. **性别匹配**：男性角色用男声，女性角色用女声
2. **年龄匹配**：少年 / 青年 / 中年 / 老年 / 不老
3. **性格匹配**：见下方"性格 → 音色"映射表
4. **角色定位**：主角用辨识度高的音色，配角用中性音色

## 国漫古风玄幻（anime）音色建议

### 男性角色
- **少年宗主 / 少年剑客**：「清亮少年音 + 沉稳底色」，语速中等偏慢，咬字带古风韵
- **仙尊 / 高冷男主**：「冷调低音 + 气息浅」，句尾不上扬，停顿长
- **热血草根男主**：「中频少年音 + 爆发力」，冲突时音高上扬 +10-15%
- **魔尊 / 反派**：「低哑 + 气息重」，句尾带气声
- **师父 / 长辈**：「温和中音 + 缓慢」，每句尾字拖长 0.2-0.3s
- **纨绔 / 浪子**：「轻佻中音 + 戏谑」，故意带点尾音上挑

### 女性角色
- **御姐 / 师尊**：「中高音女声 + 颗粒感」，声线带磁
- **少女 / 师妹**：「明亮高音 + 软糯」，但**克制使用**（避免甜宠化）
- **妖王 / 女反派**：「中低音女声 + 冷冽」，笑声带气声
- **神秘 NPC**：「气息音 + 回响」，语速慢，音量小
- **慈母**：「温和中音 + 略微沙哑」，句尾下沉

### 古风语音节奏铁律
- 关键台词（揭穿 / 反转 / 觉醒）必须**前 0.3s 静默** + **后 0.5s 回响**
- 念法术 / 口诀时**节奏化停顿**（每 4 字一停）
- 战斗怒吼**胸腔共鸣 + 0.1s 气口**

## 古装真人（real）音色建议

### 男性角色
- **帝王 / 战神**：「浑厚中音 + 压迫感」，胸腔共鸣明显，语速慢
- **中年谋士 / 丞相**：「低沉中音 + 顿挫」，每句之间停顿 0.5-0.8s
- **青年侠客**：「自然中音 + 略带沙哑」，同期声质感
- **反派太监 / 奸臣**：「尖细中音 + 阴柔」，刻意压喉
- **慈父**：「温和中音 + 略微沙哑」，句尾下沉
- **草根男主**：「自然中音 + 烟火气」，带点方言/俚语节奏

### 女性角色
- **皇后 / 太后**：「浑厚女中音 + 端庄」，字正腔圆
- **宫女 / 丫鬟**：「自然中音女声」，同期声
- **女将军**：「中音女声 + 刚硬」，字头咬重
- **江湖女子**：「中音女声 + 江湖气」，说话带点豪爽
- **苦情母亲**：「沙哑中音 + 哽咽」，哭戏要真

### 古装真人语音节奏铁律
- 关键对白**走同期声质感**，不用过度后期
- 宫廷戏**字正腔圆**，江湖戏**可带俚语节奏**
- 哭戏 / 怒吼 / 情绪爆发段必须**前有 0.5s 静默**
- 字幕同步对齐（每句尾字 +0.1s 余量）

## 风格差异化对比

| 维度 | anime | real |
|------|-------|------|
| 音色基底 | 配音演员 / CV | 同期声 / 演员 |
| 气息感 | 适度夸张 | 自然克制 |
| 戏剧化 | 情绪外放（漫感） | 情绪内敛（影感） |
| 后期处理 | 适当混响 / 空间感 | 干净干声 / 同期声 |
| 念白节奏 | 4 字一顿 / 古风韵 | 自然语流 / 字正腔圆 |
| 情绪爆发 | 胸腔共鸣 + 拖音 | 同期收 + 静默收尾 |

---

## 跨集一致性铁律

- **同一角色所有集音色锁定不变**（不允许中途换音色）
- 主角音色必须在第 1 集前 30s 内**首次开口定型**（让观众建立记忆点）
- 配角若本集无台词，可不分配音色
- 反派变装 / 易容场景：音色不变（观众靠音色认人）

---

## 旁白 / OS（内心独白）音色

- **anime 旁白**：低音成年男声 / 中音成年女声，沧桑感，混响略重
- **real 旁白**：同期声演员本人或专业配音，避免用二次元音色
- **OS 时机**：内心独白用 30-50% 音量 + 0.3-0.5s 混响

---

## 使用步骤

1. 调用 `list_voices` 查看可用音色列表
2. 调用 `get_characters` 获取所有角色信息（含 `voice_profile` 建议）
3. 调用 `get_project_style` 读取项目风格（`anime` / `real`）
4. 按 4 维匹配（性别 / 年龄 / 性格 / 定位）+ 风格音色表选定
5. 为每个角色调用 `assign_voice` 分配合适的音色
6. 汇总分配结果给用户（附带每个角色的音色理由）

## 自检清单

- [ ] anime 角色没用现代都市口音
- [ ] real 角色没用二次元"嗲音"
- [ ] 同一角色跨集音色一致
- [ ] 主角第 1 集前 30s 内开口定型
- [ ] 关键台词（前 3 秒钩子）音色辨识度高
- [ ] 反派 / 主角音色对比度强（不能让观众听混）
- [ ] 旁白 / OS 音色与正片风格一致
