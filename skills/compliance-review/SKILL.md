# 合规审核规范

## 风格硬约束

合规审核必须结合项目风格判定语境：

- **anime**（国漫古风玄幻）：玄幻 / 修仙 / 妖怪 / 神话可接受，**但不得含真实朝代政治影射**
- **real**（古装真人）：可含历史朝代，**但不得丑化民族英雄 / 歪曲历史定论**

---

## 审核范围

### 1. 政治敏感（硬红线）
- ❌ 涉及中国领导人、历史事件、政策批评的内容
- ❌ 涉及国家统一、领土主权问题的争议性表述
- ❌ 涉及军警、国家安全机关的负面描写
- ❌ **anime 题材**借"仙门 / 朝廷"影射现实政治

### 2. 历史虚无主义
- ❌ 丑化民族英雄、革命先烈
- ❌ 篡改历史定论、歪曲历史事件
- ❌ 美化反动派、卖国贼

### 3. 宗教与民族
- ❌ 宗教极端主义宣传
- ❌ 民族歧视、民族仇恨内容
- ❌ 封建迷信（算命、风水、邪教描写）
- ⚠️ **anime 题材**：修仙体系 / 法宝 / 妖怪设定属于虚构创作，不算封建迷信，**但不得借神魔宣传现实宗教**

### 4. 暴力与血腥
- ❌ 详细暴力描写（虐待、酷刑）
- ❌ 过度血腥画面描述
- ❌ 校园暴力、未成年人暴力
- ⚠️ **anime 题材**：修仙斗法 / 法术对决属类型片常规，**但不得有真实人体伤害细节**
- ⚠️ **real 题材**：武打戏点到为止，**不得有真实血腥镜头**

### 5. 色情与低俗
- ❌ 性暗示、擦边内容
- ❌ 拜金主义、物质崇拜描述
- ❌ 婚外情、小三上位的价值观导向
- ❌ 仙侠"双修"擦边（anime 严格禁止）

### 6. 违法犯罪
- ❌ 美化犯罪、传授犯罪方法
- ❌ 赌博、吸毒的正面描写
- ❌ 电信诈骗、传销等内容的细节展示

### 7. 价值观导向
- ❌ 三观不正（自私、阴险、无底线的角色作为正面典型）
- ❌ 宣扬享乐主义、攀比消费
- ❌ 挑战公序良俗的剧情设计
- ⚠️ **anime 题材**："逆袭 / 打脸"属类型片常规，**但不得宣扬以暴制恶 / 弱肉强食**
- ⚠️ **real 题材**："宫斗 / 宅斗"属类型片常规，**但不得美化阴谋诡计 / 不择手段上位**

---

## 风格一致性检查（新增）

- [ ] 整部剧 `style` 字段统一为 `anime` 或 `real`，无中途切换
- [ ] **anime 题材**未出现"霸总 / 甜宠 / 校园 / 现代都市"桥段
- [ ] **real 题材**未出现"二次元 / 港漫 / 三渲二"视觉描述
- [ ] 题材调性：修仙 / 江湖 / 神话 / 宫斗 / 战神，**不混入现代悬疑 / 科幻**
- [ ] 角色语言风格与风格一致（anime 古风韵 vs real 同期声）

---

## 已废弃风格黑名单

以下风格 / 桥段 / 调性**禁止出现在新剧本中**（无论 anime 还是 real）：

- 霸总 / 总裁契约 / 替嫁豪门
- 甜宠 / 撒糖 / 双向暗恋 / 校园恋爱
- 悬疑 / 现代刑侦 / 科幻未来
- 现代都市 / 职场 / 家庭伦理苦情
- 重生复仇 / 穿越到现代

**理由**：用户明确要求对齐"红果短剧"国漫古风玄幻 + 古装真人的双风格定位。

## 审核输出格式

### PASS（通过）
```
审核结果：✅ PASS

无违规内容。
风格一致性：anime / real
```

### FAIL（拒绝）
```
审核结果：❌ FAIL

违规类型：[政治敏感/历史虚无/暴力血腥/色情低俗/价值观导向/风格不一致]
违规位置：[集数/场景/具体台词]
违规内容：[原文引用]
违规原因：[说明]
建议修改：[如何修改以通过审核]
```

---

## 审核原则

1. **宁严勿宽**：有疑虑的内容一律标记
2. **上下文判断**：结合场景上下文判断是否违规
3. **改编尺度**：小说中的时代背景内容（民国/古代）需考虑历史语境
4. **正向引导**：即使无硬性违规，也检查价值导向是否正向
5. **风格一致**：检查是否混入已废弃风格（霸总/甜宠/悬疑/现代都市等）
