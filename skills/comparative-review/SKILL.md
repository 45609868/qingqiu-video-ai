# 质量对比审核规范

## 风格差异化评分基线

不同风格的爆款指标不同，**必须按风格分别评分**：

| 维度 | anime（国漫古风玄幻） | real（古装真人） |
|------|----------------------|------------------|
| 集长 | 60-90s | 90-120s |
| 镜头数 | 12-15 镜 | 10-13 镜 |
| 平均镜头时长 | 5-7s | 7-10s |
| 句长均值 | 8-12 字 | 10-14 字 |
| 对话占比 | 65-75% | 70-80% |
| 视觉标记密度 | 5/100 字 | 4/100 字 |
| 钩子位置 | 前 3s | 前 3s |
| 高潮密度 | 每集 1-2 个 | 每集 1 个 |

**禁止** 用同一把尺子量两个风格。

---

## 审核维度（100 分制）

### 1. 句长控制（20 分）
- **anime 满分标准**：平均句长 8-12 字
- **real 满分标准**：平均句长 10-14 字
- 短句比例（<10字）：30-40%
- 中句比例（10-20字）：50-60%
- 长句比例（≥20字）：<10%
- **扣分规则**：平均句长每高 5 字扣 2 分；长句比例每高 10% 扣 2 分

### 2. 对话比（25 分）
- 满分标准：对话占比 70-80%
- 对话数量：每 1000 字 15-25 条
- 平均对话长度：20-40 字
- **扣分规则**：对话比每低 5% 扣 2 分；60% 以下不得分

### 3. 视觉标记密度（20 分）
- 满分标准：anime 5个/100字 / real 4个/100字
- 表情词（冷笑、嗤笑）：1.5个/100字
- 眼神词（眼神一冷）：1.0个/100字
- 动作词（嘴角勾起）：1.0个/100字
- 气场词（霸气）：0.5个/100字

### 4. 网文感关键词（20 分）
- 满分标准：1.5-2.5个/100字
- 情绪强化词（冷笑、竟然）
- 态度词（不屑、轻蔑）
- 反转词（没想到）
- 打脸词（啪啪打脸）

### 5. 节奏结构（15 分）
- 满分标准：anime 12-15 镜 / 集；real 10-13 镜 / 集
- 场景数：7-10 个/集
- 开局钩子：前 3s 有强冲突（前 10% 内）
- 结尾悬念：停在答案揭晓前
- 高潮点：anime 1-2 个 / 集；real 1 个 / 集

### 6. 风格一致性（新增，10 分）
- 全剧 `style` 字段统一：5 分
- 未混入已废弃风格（霸总/甜宠/悬疑/现代都市）：3 分
- 台词语感 / 视觉描述与风格匹配：2 分

---

## 输出格式

```
【质量审核报告】

风格：anime / real
判定：PASS（≥80分）/ FAIL（<80分）
总分：XX/100

## 维度得分
- 句长控制：XX/20 [✓/⚠️]  (anime 8-12字 / real 10-14字)
- 对话比：XX/25 [✓/⚠️]
- 视觉标记：XX/20 [✓/⚠️]  (anime 5/100字 / real 4/100字)
- 网文感：XX/20 [✓/⚠️]
- 节奏结构：XX/15 [✓/⚠️]  (anime 12-15镜 / real 10-13镜)
- 风格一致性：XX/10 [✓/⚠️]

## 具体问题
1. [问题描述] → [具体修改建议]

## 修改优先级
1. 最优先：...
2. 其次：...
3. 可选：...
```

---

## 风格失分红线

- **anime 题材出现霸总 / 甜宠 / 现代都市桥段**：风格一致性直接 0 分
- **real 题材出现二次元 / 港漫 / 玄幻法术描述**：风格一致性直接 0 分
- **anime 集长超过 100s 或低于 50s**：节奏结构扣 5 分
- **real 集长超过 130s 或低于 80s**：节奏结构扣 5 分

---

## 审核原则

1. **风格先行**：先确定风格 → 用对应基线评分
2. **维度独立**：每个维度单独评分，不因某一维度极差而否定全剧
3. **重点优先**：重点看句长和对话比，这两个维度对短剧节奏影响最大
4. **可执行建议**：每条问题都要给出具体可执行的修改建议
5. **尊重原作**：在保留原作核心卖点的前提下提出修改建议
6. **风格一致**：检查是否混入已废弃风格（霸总/甜宠/悬疑/现代都市等）
