# 质量对比审核规范

## 审核维度

### 1. 句长控制（20分）
- 满分标准：平均句长 10-14 字
- 短句比例（<10字）：30-40%
- 中句比例（10-20字）：50-60%
- 长句比例（≥20字）：<10%
- **扣分规则**：平均句长每高5字扣2分；长句比例每高10%扣2分

### 2. 对话比（25分）
- 满分标准：对话占比 70-80%
- 对话数量：每1000字 15-25 条
- 平均对话长度：20-40 字
- **扣分规则**：对话比每低5%扣2分；60%以下不得分

### 3. 视觉标记密度（20分）
- 满分标准：4个/100字以上
- 表情词（冷笑、嗤笑）：1.5个/100字
- 眼神词（眼神一冷）：1.0个/100字
- 动作词（嘴角勾起）：1.0个/100字
- 气场词（霸气）：0.5个/100字

### 4. 网文感关键词（20分）
- 满分标准：1.5-2.5个/100字
- 情绪强化词（冷笑、竟然）
- 态度词（不屑、轻蔑）
- 反转词（没想到）
- 打脸词（啪啪打脸）

### 5. 节奏结构（15分）
- 满分标准：场景数 7-10 个/集
- 开局钩子：前 10% 有强冲突
- 结尾悬念：停在答案揭晓前
- 高潮点：至少 1 个高潮

## 输出格式

```
【质量审核报告】

判定：PASS（≥80分）/ FAIL（<80分）
总分：XX/100

## 维度得分
- 句长控制：XX/20 [✓/⚠️]
- 对话比：XX/25 [✓/⚠️]
- 视觉标记：XX/20 [✓/⚠️]
- 网文感：XX/20 [✓/⚠️]
- 节奏结构：XX/15 [✓/⚠️]

## 具体问题
1. [问题描述] → [具体修改建议]

## 修改优先级
1. 最优先：...
2. 其次：...
3. 可选：...
```

## 审核原则

1. **维度独立**：每个维度单独评分，不因某一维度极差而否定全剧
2. **重点优先**：重点看句长和对话比，这两个维度对短剧节奏影响最大
3. **可执行建议**：每条问题都要给出具体可执行的修改建议
4. **尊重原作**：在保留原作核心卖点的前提下提出修改建议
