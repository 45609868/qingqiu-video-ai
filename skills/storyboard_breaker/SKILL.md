# 分镜拆解指南（国漫古风玄幻 / 古装真人 双风格版）

> **风格简化为二选一**：drama.style 只能取 `anime` 或 `real`。其他历史风格已废弃。
> - `anime` → 国漫古风玄幻（参考《万妖图录》《山海藏墟》《护镖人》《大天蓬》）
> - `real` → 古装真人（参考大天蓬同类真人短剧）

## 视觉风格核心规则

**anime 风格 — 国漫古风玄幻：**
- 视觉词库（注入 image_prompt / video_prompt）：港漫勾线 / 三渲二 / 敦煌配色 / 水墨留白 / 国漫古典
- 人物比例：6-7 头身，五官写意但表情锐利
- 特效：仙剑流光 / 法阵符文 / 灵力漩涡 / 妖气弥漫 / 仙鹤云雾
- 光影：高对比 + 强轮廓光 + 冷暖对撞
- 字体（字幕安全）：古风竖排或手写楷体

**real 风格 — 古装真人：**
- 视觉词库：写实质感 / 棚拍灯光 / 古装考究 / 兵器金属反光
- 人物比例：写实 7-8 头身，演员真脸
- 特效：实拍威亚 + 后期合成（不靠 AI 渲染）
- 光影：自然光 / 暖黄灯笼 / 烛火摇曳
- 字体：古风横排

---

## 镜头要素（12 字段必须全填）

1. **镜头标题**：3-8 字概括（如"妖核现世"）
2. **时间**：具体时分 + 光线（"戌时 烛火昏暗"）
3. **地点**：完整空间描述（"青云宗·藏经阁二楼·东侧"）
4. **景别**：远景 / 全景 / 中景 / 近景 / 特写 / 极端特写
5. **角度**：平视 / 仰拍 / 俯拍 / 侧拍 / 背面 / 过肩
6. **运镜**：固定 / 缓推 / 速推 / 缓拉 / 速拉 / 横摇 / 跟拍 / 环绕 / 升降 / 希区柯克
7. **动作**：谁 + 具体怎么做 + 肢体细节 + 表情
8. **对话**：完整台词（无则写"无"，禁止留空）
9. **画面结果**：动作的即时后果 + 视觉细节
10. **氛围**：光线 + 色调 + 声音 + 整体氛围
11. **时长**：3-8 秒（不要超过 10 秒，超长台词必须拆）
12. **9:16 构图**：构图位置（人脸安全区 / 字幕安全区 / 上下空间分配）

---

## 9:16 竖屏构图硬规则（必须严格遵守）

### 画框分区
- **上 1/3**：天 / 飞剑 / 屋檐 / 远山 — 用于环境信息
- **中 1/3**：人物主体（眼睛在画面 1/3 高度）— 黄金视线
- **下 1/3**：地面 / 法阵 / 字幕位置 — 留出字幕安全区（距底 ≥ 80px）

### 人物安全区
- 眼睛位置：画面 **上 1/3 分界线 ±5%**（观众第一视线落点）
- 头部上方留白：≥ 15% 画框（避免压迫感）
- 字幕区域：**画面底部 18% 禁止放置重要视觉元素**
- 武器 / 法器高度：不超过画框上 1/3 分界线

### 景别分配（每集 12-15 镜必须轮换）
- 全景：≤ 2 个（开场定调 / 结尾收束）
- 中景：3-4 个（对话 / 动作）
- 近景：4-5 个（情绪 / 对话高潮）
- 特写：2-3 个（眼睛 / 手部 / 道具细节）
- **禁止 3 个连续同景别**

### 运镜术语（anime 风格专属）
- **缓推镜头（dolly in slow）**：主角揭秘 / 强敌逼近 / 情绪升温
- **速推镜头（push in fast）**：冲突爆发 / 反转揭穿
- **希区柯克变焦**：心理冲击 / 真相时刻 / 恐惧感
- **环绕镜头（orbit）**：高手登场 / 法阵启动 / 妖兽化形
- **跟拍（follow）**：追逐 / 逃跑 / 飞剑
- **拉远 + 慢动作（pull out + slowmo）**：情绪释放 / 牺牲 / 大招前蓄力
- **低角度仰拍（low angle）**：神将 / 反派 / 压迫感
- **俯拍（top down）**：阵法 / 战场 / 群妖
- **特写切换（insert cut）**：眼睛 / 武器 / 法器细节

### 光影与色调（anime）
- **暖色调**：金黄 / 朱红 / 琥珀 — 仙门 / 皇宫 / 热血
- **冷色调**：青蓝 / 墨绿 / 霜白 — 秘境 / 鬼域 / 紧张
- **高对比光**：剑光 / 雷电 / 火焰中心
- **剪影**：逆光战斗 / 飞剑划过
- **氛围光**：灯笼 / 烛火 / 灵火 / 鬼火

## 红果短剧 — 前 3 秒强钩子 12 种 pattern

第 1 镜必须是以下之一（前 3 秒抓住观众）：

1. **冲突开门见山型**
   - "你找死！"（角色直接开打 / 开骂）
   - 示例：反派一脚踹开庙门，"逆贼，拿命来！"

2. **身份揭穿型**
   - 主角隐藏身份被揭穿，反派惊呼
   - 示例：丫鬟掀开主角面纱，惊恐后退

3. **危险逼近型**
   - 妖兽 / 反派逼近，主角背对镜头不知情
   - 示例：主角背对悬崖缓步后退，脚下碎石掉落

4. **悬念留白型**
   - 一句未说完的台词
   - 示例："其实那天晚上，我……"（被打断）

5. **时空错位型**
   - 主角穿越 / 重生瞬间
   - 示例：金光一闪，主角睁开眼发现自己回到十年前

6. **血溅当场型**
   - 突然见血 / 出现尸体
   - 示例：主角转身，身后侍卫胸口插着剑

7. **法宝现世型**
   - 主角觉醒法宝 / 觉醒血脉
   - 示例：主角手心浮现古纹，光芒四射

8. **身份反转型**
   - 主角被当成乞丐 / 废物，实则身份惊人
   - 示例："这废物能有什么后台？"（镜头切到皇宫急报）

9. **环境突变型**
   - 原本平静场景突然出大事
   - 示例：茶楼突然地震，妖兽从地下破土

10. **告白失败型**（虐剧专用）
    - 刚要表白，对象已成他人
    - 示例：主角捧着花，看到女主嫁他人

11. **误会加深型**
    - 刚解释清楚，又被误会
    - 示例：女主刚被打动，丫鬟进来说"夫人，少爷又带了新欢"

12. **觉醒金手指型**（男频爽剧专用）
    - 主角觉醒系统 / 获得上古传承
    - 示例：主角濒死之际，体内响起古老声音

## 中段节奏 — 12-15 镜标准结构

```
镜 1：强钩子（前 3 秒抓人）
镜 2-3：建立人物关系 / 推进
镜 4-5：小冲突 / 第一个疑问
镜 6-7：信息揭晓 / 第一个反转
镜 8-9：危机升级
镜 10-11：高潮对决 / 情绪爆发
镜 12：悬念 / 钩子结尾（"下一集 X 即将发生"）
```

每 2-3 镜必须有：
- 一次信息变化（揭示新信息）
- 一次情绪变化（升温或反转）
- 一次景别变化（不能连续 3 个同景别）

---

## 镜头时长公式

- 标准公式：**台词字数 ÷ 3 = 秒数**（中文）
- 最小时长：1.5 秒（纯动作 / 表情特写）
- 标准时长：3-6 秒
- 最大时长：10 秒（超长必须拆镜）

## video_prompt 标准格式（覆盖完整 duration）

**anime / 国漫古风玄幻 格式：**

```
0-{n}秒：<location>地点</location>，{景别}，<role>{角色名}</role>{动作+台词+表情}，{光影描述}，{特效描述}。
<{n}-{m}>秒：<location>地点</location>，{景别变化}，<role>{角色名}</role>{动作+表情}，{运镜描述}，{光影延续}。
<{m}-{duration}>秒：<location>地点</location>，{收尾景别}，<role>{角色名}</role>{结果+余韵}，{氛围收束}。
```

**real / 古装真人 格式：**

```
0-{n}秒：{景别}，{角色名}{写实动作+台词+微表情}，{真实光影}，{写实质感}。
<{n}-{m}>秒：{景别}，{角色名}{动作+表情变化}，{运镜}，{环境细节}。
<{m}-{duration}>秒：{收尾景别}，{角色名}{结果}，{氛围}。
```

**prompt 必备尾缀：**
- anime：`9:16 vertical, Chinese animation style, cinematic lighting, no subtitles, no on-screen text, high quality`
- real：`9:16 vertical, live action, cinematic, photorealistic, no subtitles, no on-screen text`

## 角色一致性锚点（最重要！）

每个镜头的 `character_ids` 引用角色时，必须在 `image_prompt` / `video_prompt` 中**写死**该角色的：
- 发色 + 发型（如"银白长发高马尾"）
- 服装主色 + 配饰（如"玄青长袍 + 暗金腰封 + 玉佩"）
- 标志性外观（如"左眼斜疤"）

**禁止**用"红衣女子"这种泛指。**必须**"朱砂红襦裙 + 飞天髻 + 眉心花钿的女子"。

## 使用流程

1. 调用 `read_storyboard_context` 读取剧本、角色、场景、已有分镜
2. 根据 drama.style（anime/real）选择对应视觉词库
3. 选第 1 镜钩子 pattern，按 12-15 镜标准结构铺
4. 每个镜头写 12 字段 + 视觉词库注入
5. 自检清单全过
6. 调用 `save_storyboards` 一次性保存

## 场景关联规则

- 优先用 `read_storyboard_context` 返回的 scenes
- `location + time` 可明确匹配时必须回填 `scene_id`
- 同一集同一 location+time 只用一次

## 角色绑定规则

- `character_ids` 严格从 `read_storyboard_context` 返回的角色列表选
- 镜头有 0 到多个角色
- 出镜 / 说话 / 发生动作 / 被看见都要绑
- 纯环境 / 空镜 / 物件镜可传空数组
